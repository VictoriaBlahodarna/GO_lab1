# Лабораторна робота №2: Тестування програмного забезпечення

## Тема:
Ознайомлення з методологією тестування програмного забезпечення в мові
програмування Go, застосування основних підходів до написання тестів, аналіз покриття
коду тестами та оцінка якості тестування.

## Мета роботи:
Метою лабораторної роботи є набуття практичних навичок написання якісних тестів для коду на Go, розуміння принципів покриття тестами, робота зі сценаріями успішного (success flow), помилкового (fail flow) виконання та обробкою граничних випадків (edge cases).

## Завдання:
### Студент повинен:
1. Ознайомитися з пакетом testing у Go.
2. Написати тести для простої функції (success flow, fail flow, edge cases).
3. Застосувати table-driven tests для покращення якості тестування.
4. Використати go test -cover для аналізу покриття коду тестами.
5. Визначити, що робить тести якісними, і провести їх рефакторинг за необхідності.
