# Лабораторна робота №3: Структура WEB застосунку
## Тема:
Проєктування та реалізація структури WEB-застосунку мовою програмування Go із
застосуванням архітектури REST, взаємодії з базою даних Postgres та реалізацією бізнеслогіки.
## Мета роботи:
Метою лабораторної роботи є закріплення практичних навичок побудови веб-застосунку
на Go, правильного структурування коду за пакетами, створення REST API-сервера,
організація роботи з базою даних Postgres та впровадження базової бізнес-логіки.

Студент повинен:

https://github.com/VictoriaBlahodarna/GO_lab1/lab3.
- [x] 3. Інтегрувати бізнес задачу з лабораторної 2 в шаблон (додати хендлер, базу данних)

- [x] 5. Бажано реалізувати додатково операцію отримання сутності.
- [x] 6. Бажано написати тести для написаної логіки.
