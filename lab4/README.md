# Лабораторна робота №4: CSV імпорт та аналіз продуктивності
## Тема:
Ознайомлення з методами імпорту CSV-файлів у Go, обробки та аналізу даних, а також оцінки продуктивності під час роботи з великими наборами даних.
## Мета роботи:
Метою лабораторної роботи є набуття навичок побудови імпортів CSV-файлів за допомогою мови Go; Ознайомлення зі стандартними бібліотеками для роботи з CSV; Аналіз продуктивності та ефективності роботи програми під час обробки великих CSVфайлів; Оптимізація роботи з великими обсягами даних для покращення швидкості виконання.
