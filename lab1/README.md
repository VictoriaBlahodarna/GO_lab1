## Керування списком працівників компанії
Створіть структуру Position, що містить:
• Назву посади
• Мінімальну зарплату
• Максимальну зарплату
Структуру Employee, яка містить:
• ID працівника
• Ім'я
• Посаду (Position)
• Фактичну зарплату
Реалізуйте метод, що перевіряє, чи зарплата працівника відповідає діапазону його посади.
Використовуйте map[Position]Employee для збереження працівників та реалізуйте
функцію, яка знаходить працівника з найближчою до максимальної для посади зарплатою.
